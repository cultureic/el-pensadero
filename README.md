# El Pensadero

Wiki de fans de Harry Potter, en español: cartas de personajes, hilos entrelazados, conceptos, misterios sin resolver, cronología, lugares reales y una sala de juegos con sprites en pixel art dibujados a mano.

Es un sitio estático de un solo archivo (`index.html`) con sus imágenes en `img/`. No necesita servidor ni dependencias: abre `index.html` o sírvelo con cualquier servidor estático (por ejemplo `npx serve .`).

## Enlaces directos

Las secciones y las fichas se pueden enlazar con una almohadilla: `#juegos`, `#misterios`, `#harry`, `#h-profecia`.
